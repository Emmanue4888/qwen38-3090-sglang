## ❓ Troubleshooting

### Common Issues and Fixes

**"CUDA Out of Memory" Error**
- Close other programs that use graphics memory.
- Reduce the response length in settings.
- Try the "Eco Mode" if available in your version.

**App Won't Start**
- Make sure your NVIDIA drivers are updated.
- Restart your computer and try again.
- Check that you have at least 16 GB RAM free.

**Slow Performance**
- Check your GPU temperature (should be under 85°C).
- Close background tasks like browsers and games.
- Make sure the power cable is plugged directly into the GPU.

**"File Not Found" Error on Double-Click**
- Right-click the EXE file → "Run as Administrator".
- Temporarily disable antivirus during first launch.
